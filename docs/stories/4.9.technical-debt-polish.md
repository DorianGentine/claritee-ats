## Acceptance Criteria

### Rate limiting (priorité haute)
1. Rate limiting appliqué sur toutes les mutations tRPC exposant des écritures en base :
   - `candidate.create`, `candidate.update`, `candidate.delete`
   - `note.create`, `note.update`, `note.delete`
   - `offer.create`, `offer.update`, `offer.delete`
   - `clientCompany.create`, `clientCompany.update`, `clientCompany.delete`
   - `clientContact.create`, `clientContact.update`, `clientContact.delete`
   - `tag` (create via findOrCreate), `candidature.create`, `candidature.updateStatus`, `candidature.delete`
2. Limites raisonnables par utilisateur (ex. 60 mutations/min pour les mutations générales)
3. Erreur `TOO_MANY_REQUESTS` avec message générique si dépassement
4. Clé de rate limit : `"mutation:${ctx.user.id}"` (par utilisateur authentifié, pas par IP)

### AlertDialog (priorité moyenne)
5. Toutes les confirmations de suppression utilisent `AlertDialog` de shadcn/ui à la place de `window.confirm()`
6. Écrans concernés : suppression candidat (Story 2.4), suppression expérience (2.6), suppression formation (2.7), suppression offre (3.4), dissociation candidature (3.8), suppression note candidat (3.9), suppression note offre (3.10), suppression note libre (3.12), suppression contact client (3.2)
7. `AlertDialog` réutilisable extrait dans `src/components/shared/ConfirmDialog.tsx` (ou réutilisation de celui existant s'il existe déjà)
8. Style cohérent : titre court, message de confirmation, bouton "Annuler" + bouton destructif "Supprimer"

### Déplacer vers une offre (priorité basse)
9. Dans la page "Mes notes" (`/notes`), le dialog d'édition d'une note libre expose un dropdown "Déplacer vers une offre"
10. Le dropdown est alimenté par `offer.list` (offres du cabinet, triées par date)
11. Sélectionner une offre appelle `note.moveToOffer` (API déjà implémentée en Story 3.12)
12. Après déplacement, la note disparaît de "Mes notes" (elle n'est plus libre)
13. Toast de confirmation : "Note déplacée vers [titre de l'offre]"

**Réf.** Rétrospective Epics 1–3 (2026-05-08) ; `src/lib/rate-limit.ts` ; `docs/architecture/coding-standards.md` §5
