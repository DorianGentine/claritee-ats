# Story 5.8: Drag & Drop villes candidat (dnd-kit)

## Status

TODO

## Story

**As a** recruiter,
**I want** to reorder candidate cities by drag & drop,
**so that** city prioritization feels natural and fast.

## Acceptance Criteria

1. Packages installés en versions exactes : `@dnd-kit/core`, `@dnd-kit/sortable`, `@dnd-kit/utilities`
2. `CityAutocomplete` en `mode="multi"` avec `ordered={true}` : chips devenus draggables via `SortableContext` + `useSortable`
3. Handle de drag visible (icône grip — `GripVertical` de `lucide-react`) à gauche de chaque chip
4. Boutons ↑↓ de la story 5.3 retirés — remplacés par le drag & drop
5. L'ordre est mis à jour localement (optimiste) dès le drop via `onChange`
6. La mutation `candidate.update` est appelée avec le nouvel ordre après le drop (persisté en base)
7. Accessible au clavier : espace pour saisir un item, flèches pour déplacer, espace pour déposer
8. En mode `ordered={false}` (`ClientCompany`) : aucun drag & drop, comportement inchangé
9. Tests : simulateur dnd-kit → état mis à jour dans le bon ordre + mutation appelée

### Component Specifications

**Packages dnd-kit :**
- `@dnd-kit/core` : `DndContext`, `useSensors`, `useSensor`, `PointerSensor`, `KeyboardSensor`
- `@dnd-kit/sortable` : `SortableContext`, `useSortable`, `verticalListSortingStrategy`, `arrayMove`, `sortableKeyboardCoordinates`
- `@dnd-kit/utilities` : `CSS` (pour `transform` dans le style du composant draggable)

**Structure `SortableCityChip` :**
```tsx
const SortableCityChip = ({ city, onRemove }: { city: CityOption; onRemove: () => void }) => {
  const { attributes, listeners, setNodeRef, transform, transition, isDragging } = useSortable({ id: city.id })
  const style = { transform: CSS.Transform.toString(transform), transition, opacity: isDragging ? 0.5 : 1 }
  return (
    <div ref={setNodeRef} style={style} className="flex items-center gap-1 ...">
      <GripVertical className="cursor-grab" {...attributes} {...listeners} />
      <span>{city.name}</span>
      <button onClick={onRemove}>×</button>
    </div>
  )
}
```
