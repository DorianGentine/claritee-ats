# Story 4.6: Public Candidate Page - Anonymous Version

## Status

DONE

## Story

**As a** recruiter,  
**I want** to share an anonymized candidate profile,  
**so that** I can prospect new clients without revealing candidate identity.

## Acceptance Criteria

1. Anonymous share type generates different token  
2. Public page shows candidate profile WITHOUT:
   - firstName, lastName (replaced with "Candidat anonyme")
   - Photo (replaced with generic avatar)
   - Email, phone, LinkedIn (hidden)
   - Company names in experiences (replaced with "[Entreprise]")
   - School names in formations (replaced with "[École]")
3. Shows: title, city, summary, experience descriptions, formation fields, languages  
4. Professional layout, same structure as normal version  
5. "Fiche anonymisée" badge visible on page  
6. Recruiter's company branding still visible  
7. CTA: "Intéressé par ce profil? Contactez [company name]"  
8. Link to recruiter's company contact or email  
9. Same expiration logic as normal shares  
10. Cannot "de-anonymize" from public page  

**Réf.** PRD `docs/prd.md` § Epic 4, Story 4.6 ; Wireframes §8 version anonymisée ; route `src/app/share/[token]/` [Source: docs/architecture.md §6, docs/frontend-architecture.md §2]

## QA Results

### Code Review — 2026-04-04

**Reviewer :** claude-sonnet-4-6

#### Points positifs

- **Masquage 100% serveur** : `mapToAnonymousPublicDto()` s'exécute dans `publicCandidateSelect.ts` avant tout rendu ; les champs `firstName`, `lastName`, `email`, `phone`, `linkedinUrl`, `photoUrl` ne transitent pas vers le client.
- **`publicCandidateSelect` inchangé** : un seul `select` Prisma pour NORMAL et ANONYMOUS — pas de dérive entre les deux requêtes.
- **DRY solide** : `ProfileSectionsGrid` élimine ~100 lignes de JSX dupliqué. Résumé, langues, expériences, formations partagés sans conditionnel.
- **Discriminant `type`** sur le retour tRPC : utile en tests, sans casser les assertions existantes sur `data.firstName`.
- **`generateMetadata` sécurisé** : ANONYMOUS → titre générique, pas d'exposition du nom du candidat dans les balises `<title>`/`<meta>`.
- **Comportement erreurs cohérent** : token ANONYMOUS expiré → même `FORBIDDEN TOKEN_EXPIRED` que NORMAL, pas de fuite de type.
- **Couverture** : 15 tests RTL + 2 nouveaux tests d'intégration, 27 tests unitaires au total tous verts.

#### Points à surveiller

1. **CTA sans mailto (AC 8)** : limite MVP documentée — `Company` n'a pas de champ email. À adresser si l'on ajoute un email cabinet au schéma.
2. **IDs d'expériences/formations dans le DTO anonyme** : les `id` (UUIDs) sont présents dans `AnonymousPublicCandidate` pour les keys React. Ils ne permettent pas de reconstituer l'identité mais sont à surveiller si la politique change.
