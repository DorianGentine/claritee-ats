# Story 5.2: Procédure tRPC city.autocomplete

## Status

done

## Story

**As a** developer,
**I want** a `city.autocomplete` tRPC procedure,
**so that** the frontend can search cities with local-first, Photon fallback logic.

## Acceptance Criteria

1. Router `city` créé (`src/server/trpc/routers/city.ts`) et enregistré dans `_app.ts`
2. Procédure `city.autocomplete` : `publicProcedure`, input `{ q: string }`, output `{ id, name, region, country }[]`
3. Si `q.length < 3` → retourne `[]` immédiatement sans requête DB
4. Recherche locale : `$queryRaw` avec `unaccent(name) ILIKE unaccent($1) || '%'`, `ORDER BY name ASC`, `LIMIT 5`
5. Si résultats locaux → retourne sans appel externe
6. Si aucun résultat local → appel Photon (`lang=fr`, `limit=5`, `layer=city`, `bbox=-10,35,40,72`)
7. Résultats Photon non présents en DB → créés à la volée via `upsert` sur `(name, country)`
8. Si Photon inaccessible (timeout ou erreur réseau) → `console.error` + retourne `[]` sans exception côté client
9. Coordonnées `latitude`/`longitude` non exposées dans l'output
10. Tests unitaires : q < 3 → [] ; DB locale trouvée → retour direct ; DB vide + Photon mocké → upsert + retour ; DB vide + Photon KO → []

### API Specifications

**Photon API :**
```
GET https://photon.komoot.io/api/?q={q}&lang=fr&limit=5&layer=city&bbox=-10,35,40,72
```
Réponse :
```json
{
  "features": [{
    "properties": { "name": "Lyon", "state": "Auvergne-Rhône-Alpes", "country": "France" },
    "geometry": { "coordinates": [4.8357, 45.7640] }  // [longitude, latitude]
  }]
}
```
Note : `geometry.coordinates[0]` = longitude, `geometry.coordinates[1]` = latitude (ordre GeoJSON).

**Contrainte `@@unique([name, country])` sur `City` :**  
Nécessaire pour l'upsert Photon. Si oublié dans 5.1, ajouter en début de cette story et générer une migration additive.

**Pas d'index GIN :**  
La table `cities` ne dispose pas d'index trigram — Prisma ne gère pas les index GIN nativement et les supprime comme drift. Pour une table de ~70–200 villes, une recherche `ILIKE` séquentielle est largement suffisante. La requête `$queryRaw` reste inchangée :
```sql
SELECT id, name, region, country
FROM cities
WHERE unaccent(name) ILIKE unaccent($1) || '%'
ORDER BY name ASC
LIMIT 5
```

**`publicProcedure` :** les villes sont des données de référence non sensibles — pas besoin d'authentification pour l'autocomplétion. [Source: ADR 0005 §6]

### Technical Constraints

- `$queryRaw` retourne des objets avec types raw Postgres (Decimal, etc.) — caster `latitude`/`longitude` en Number si besoin mais ils ne sont pas dans l'output
- Ne pas utiliser `findMany` avec `contains` pour cette recherche : elle ne tire pas parti de l'index GIN `unaccent`. Utiliser `$queryRaw`
- Timeout Photon : utiliser `AbortSignal.timeout(3000)` dans le `fetch` pour éviter de bloquer la procédure indéfiniment
- `console.log` interdit (ESLint warn) — utiliser `console.error` pour les erreurs Photon
